# CloudStore ☁️

CloudStore is a beginner-friendly serverless self-storage application built with Amazon Web Services (AWS).

## Project Goal

The application will allow users to register, log in, and manage their own self-storage records securely.

## AWS Services

- Amazon S3 – Website hosting
- Amazon CloudFront – Secure website delivery
- Amazon Cognito – User authentication
- Amazon API Gateway – Backend API
- AWS Lambda – Serverless application logic
- Amazon DynamoDB – Database
- Amazon SNS – Asynchronous notifications
- AWS SAM – Infrastructure as Code

## Planned Features

- User registration and login
- Create, view, update, and delete storage records
- Secure access to individual users' records
- Notifications when storage records are created
- Automated infrastructure deployment

## Technologies

- AWS
